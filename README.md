# Домашнее задание к занятию "`Резервное копирование`" - `Гуреев Юрий`


### Задание 1

- Составьте команду rsync, которая позволяет создавать зеркальную копию домашней директории пользователя в директорию /tmp/backup
- Необходимо исключить из синхронизации все директории, начинающиеся с точки (скрытые)
- Необходимо сделать так, чтобы rsync подсчитывал хэш-суммы для всех файлов, даже если их время модификации и размер идентичны в источнике и приемнике.
- На проверку направить скриншот с командой и результатом ее выполнения

### Решение

Команда для выполнения данной задачи:
`rsync -avh --delete --exclude='/.*/' --checksum ~/ /tmp/backup/`
Для создания полной резервной копии используется параметр `--delete`, который удаляет из каталога назначения файлы отсутствующие в источнике.
Для исключения файлов и директорий из синхранизации используется пареметр `--exclude` со указанием маски в значении параметра (.*), не забываем экранировать символы.
Для подсчета хэш-сумм используется параметр `--checksum`.
